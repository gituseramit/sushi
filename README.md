# 🍣 SuShi — Luxury Japanese Restaurant & Order Web App

> Modern, high-end Japanese sushi restaurant landing page and order web application featuring minimalist luxury aesthetics, 3D isometric food renders, soft floating background garnishes, and smooth Lenis inertia scroll animations.

![SuShi Hero Preview](/public/images/hero_sushi.jpg)

## 🌟 Key Features

- **Fluid Inertia Scrolling**: Integrated **Lenis** smooth scrolling engine with elastic entrance reveals.
- **Custom 3D Isometric Food Graphics**:
  - **Hero**: Chopsticks reaching toward wild salmon and bluefin tuna nigiri with mouse parallax tilt.
  - **About Us**: Gourmet maki trio topped with bright red tobiko caviar encircled by fine geometric line paths.
  - **Popular Dishes**: Kawaii sushi platter, sushi and chopsticks platter, and Imperial nigiri platter with card hover elevation (`translateY(-8px)`).
  - **Featured Promo**: Chopsticks dipping salmon cheese sushi into savory soy sauce with splash ripples and fresh wasabi.
  - **Newsletter**: Overlapping salmon nigiri with lemon slice and mint leaf bleeding over espresso card boundaries.
- **Rotating Circular Badge**: Infinite rotating seal reading `SIMPLE ISN'T EASY • TO BE GOOD FOOD IS IMPORTANT •`.
- **Slide-Over Cart Drawer**: Real-time cart calculation, quantity adjusting stepper, complimentary binchotan insulated packaging, and confetti checkout confirmation.
- **Live Order Tracking**: Interactive 5-stage progress tracker with simulated route map and courier details.
- **Culinary Sound Haptics**: Web Audio API synthesized ambient chime and click sound effects with a navbar sound toggle.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Animation & Scroll**: Lenis Smooth Scroll, Framer Motion
- **Icons**: Lucide React
- **Celebrations**: Canvas Confetti
- **Audio Engine**: Native Web Audio API

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/gituseramit/sushi.git

# Navigate to project directory
cd sushi

# Install dependencies
npm install

# Start development server
npm run dev
```
